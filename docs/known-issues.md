# Known Issues

## Document Role

Tracks defects, limitations, and deferred concerns that were found but not fixed in the current increment cycle. Each entry is added during the promote phase and removed when the issue is resolved and verified. Entries are not a backlog — they are a shared signal about current system state.

## Adding an Entry

Copy the row template below and fill in all fields:

```
| KI-<n> | <context / feature area> | <one sentence: what misbehaves and under what condition> | <date YYYY-MM-DD> | <workaround or "None"> |
```

Remove from **Open** and add to **Resolved** (with the fixed date) once addressed.
